# GitHub release

Repository: https://github.com/sivajisj2/agentic-trip-planner

Clone the existing repository rather than creating another one.

```bash
git clone https://github.com/sivajisj2/agentic-trip-planner.git
cd agentic-trip-planner
python3 -m unittest discover -s tests -v
```

For updates, create a branch, review changes, and open a pull request. Keep marketplace ZIPs, secrets, and private traveler information out of Git. Public source can be viewed and downloaded; choose a distribution license and marketplace pricing before publication.
