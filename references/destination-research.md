# Destination research

Use available agent tools, including Agensi-provided tools only if actually connected. Search tourist attractions, restaurants, hotels and cafes (the four categories in TripSync AI); other categories may be supported by the agent but require explicit mapping. Capture place name, stable identifier, category, rating and scale, coordinates if available, URL, research date, opening hours, accessibility, approximate visit duration, prices, and confidence. Do not invent missing fields.

Normalize ratings to a 0–5 scale before scoring; if a source uses another scale, show conversion. De-duplicate by stable place ID or name/address, retaining the highest-quality record. Cross-check critical facts with official venue/provider sources when possible. Never represent a map URL as evidence of live opening hours. If tools are unavailable, work from user-provided places and label research incomplete.
