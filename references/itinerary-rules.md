# Itinerary construction and validation

Plan by local dates and time zone. Verify availability, opening hours, and travel durations using reliable tools; otherwise label as estimates and leave buffers. Group nearby places using researched route times, not raw lat/lon distances. Avoid overlapping activities and excessively packed days. Keep meals, rest and accessibility requirements visible. Treat hotel check-in/out and transit as explicit activities when relevant.

Separate draft from final: show choices and alternatives, ask for approval, then finalize. Never make reservations or payments without user authorization. Run the itinerary validator to catch overlapping intervals, invalid times, and negative cost values. The script cannot validate real-world route times, accessibility, booking availability, or live prices.
